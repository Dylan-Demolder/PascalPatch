Get PascalPatch

  1. Install PascalPatch and point it at your Melee Unlocked build and your own NTSC 1.02 disc.
  2. Open Browse in the app. It downloads this site's signed index and shows every plugin here.
  3. Install a plugin, turn it on, and press Play. In game, F2 opens the plugin window.

The app only installs what this site's index lists, and only when the download matches the index's SHA-256 and the index's Ed25519 signature checks out against the key built into PascalPatch. Plugins run offline: PascalPatch refuses every network request the game makes.

Make a plugin

A plugin is a Windows DLL that exports pp_plugin_load and talks to the game through pascalpatch/plugin.h: read and write game memory, call and hook game functions, run code every frame, declare settings for the F2 window, and draw on the HUD.

#include "pascalpatch/plugin.h"

static const pp_host* H;
static void frame(void*) {
  if (H->setting_number("hello", "show") != 0)
    H->hud_text(20, 20, 0xF5C542FF, 24, "Hello, Melee");
}

extern "C" __declspec(dllexport) int pp_plugin_load(const pp_host* host, const char*) {
  if (!PP_HOST_HAS(host, hud_text)) return 1;
  H = host;
  H->declare_setting("hello", R"({"key":"show","type":"bool","label":"Show greeting","default":true})");
  H->on_frame(frame, nullptr);
  return 0;
}

Package it as a ZIP with plugin.json and <id>.dll, and open a pull request on this site's repository. Every package is reviewed before its hash goes into the signed index.
