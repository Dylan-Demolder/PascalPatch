Draws a GameCube controller in a corner of the screen: the control stick and C-stick positions,
A, B, X, Y, Z and Start, the D-pad, and how far L and R are pressed. Handy for practice,
tutorials and recordings.

Pick the port, the corner, the size and the opacity in the F2 window; changes show at once.
It only reads the controller state the game already reads, and never changes the game.
