Instant, specific feedback on Melee's timing-heavy techniques, so every attempt teaches you
something:

- **L-cancels**: `Nair L-cancelled (3/7)`, or `L 5 frames early`, `L-cancel: 2 frames late`,
  `Missed L-cancel`.
- **Hops**: `Short hop` or `Full hop` off every jump.
- **Wavedashes**: `Wavedash: frame 1 (perfect), 17 deg`, or which airborne frame the air dodge
  came on; it also warns when the stick was not angled down.
- **Techs**: `Teched forward`, or `Missed tech: L/R 6 frames early`.

A tally on the left keeps your success rate for the match (L-cancel 14/17, 82%);
press **F8** (or the key you choose) to reset it. Coach one port or every human player.

The windows it checks are the game's own: 7 frames for an L-cancel, 20 for a tech. If you run the
port with auto L-cancel turned on, every landing counts as cancelled.

Read-only: it never changes the game.
