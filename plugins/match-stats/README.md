The numbers behind every match, Slippi-style, with no Slippi involved.

When a match ends, a card shows each player's:

- **Kills** and **openings** (punishes started), **openings per kill** and **damage per
  opening**: how well you convert.
- **Neutral wins**: openings started while nobody was being punished.
- **Damage** dealt, **L-cancel** rate and **inputs per minute**.

Hold **F4** during a match to see the card live. Tap it on the results screen to dismiss it.

Each finished match (longer than ten seconds) is also added as one line of JSON to
`match-stats.jsonl` beside the plugin, so you can chart your progress over a session or a month.
Turn that off in the F2 window if you prefer.

Read-only: it never changes the game.
