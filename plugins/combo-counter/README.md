A live combo counter: while a combo is running, `4 HITS 37%` in the attacker's colour under the
timer; when it ends, the total stays up for a moment (`5 hit combo, 52%, KILL`). Each player's
best combo of the match is kept in the bottom-right corner.

A combo lasts while the victim stays punished (hit, tumbling, grabbed, thrown, knocked down,
teching) or gets fewer than 45 frames to act between hits: the same rule Slippi's stats use, so
the numbers agree with the replays you are used to. Both the threshold and the minimum number of
hits to show are settings.

Read-only: it never changes the game.
